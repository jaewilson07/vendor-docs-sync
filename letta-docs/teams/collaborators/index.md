Add collaborators from your organization settings in the [Letta web app](https://chat.letta.com). Membership lets teammates use the same organization while keeping each person’s agents and conversations private by default.

## Invite a collaborator

1. Open the [organization members page](https://chat.letta.com/preferences/organization/members).
2. Select **Invite member** and enter the collaborator’s work email.
3. Send them the generated invitation link.

After accepting the invitation, the collaborator joins as an Editor. An Admin can change their role from the member’s actions menu.

## Give collaborators access to agents

A new organization member can see agents they create and agents that other members share with the organization. They do not automatically receive access to every existing agent or conversation.

To make an agent available to the team, open the agent’s settings, select **Share agent**, and choose **Anyone in your organization**. Each collaborator can then start and keep their own conversations with the shared agent.

See [Configuring permissions](/teams/permissions/index.md) for organization roles and the visibility rules for agents and conversations.
